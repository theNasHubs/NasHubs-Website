# NasHubs Website

Website giới thiệu ứng dụng NasHubs, xây dựng bằng React, Vite và Tailwind CSS.

## Yêu cầu

- Node.js 20 trở lên
- npm 10 trở lên

## Chạy local

```bash
npm install
npm run dev
```

Mở địa chỉ Vite hiển thị trong terminal (mặc định là `http://localhost:5173`).

## Kiểm tra bản production

```bash
npm run build
npm run preview
```

Thư mục `dist/` được tạo bởi lệnh build và có thể triển khai lên bất kỳ dịch vụ static hosting nào.

## Các lệnh khác

```bash
npm run lint
npm run typecheck
```
